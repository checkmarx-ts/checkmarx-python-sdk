* [Add] RepoManagerAPI.get_scm_types (GET /api/repos-manager/scm-types) -- the catalog of SCM types (id, name, displayName, scope) the UI takes `typeId` from when registering an SCM with create_oauth_based_scm, returned as the new ScmTypeInfo dataclass. Distinct from get_all_scm_types_v2, which lists the SCM instances registered in the tenant. The route is not in the published Swagger; shape taken from the Checkmarx One UI's own call.
* [Fix] RepoManagerAPI.get_job_status (GET /api/ssegateway/job-status) raised IndexError when the server-sent-events stream carried no progress event (no running job, or none reported yet). It now reads only `data:` lines, ignores keep-alives and malformed payloads, and returns None when there is no percentage; batch_import_repo keeps polling (still bounded by max_wait_per_round) instead of crashing. It also no longer sends the copied Chrome/Windows browser headers, only accept and Accept-Encoding.
